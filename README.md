# SZU 深圳大学 电费查询与预测助手

## 项目简介

夏日炎炎，空调是必不可少的伙伴。但您是否也遇到过因宿舍“五级能耗”(划重点)空调运行，导致电量不足而突然断电的尴尬情况？

本项目旨在解决这一常见问题。通过对接学校官方的电费查询接口，实现了验证码的自动识别与处理，从而帮助您便捷地获取最新的电费使用详情。

考虑到官方接口数据通常存在一定延迟（一般只能查询到三日前的数据），本项目引入了机器学习算法对历史用电数据进行分析，以预测未来的电量消耗趋势。这样，您可以提前预知可能的欠费情况，从容应对，避免因突然断电造成的不便。

## 主要功能

*   **验证码自动处理**: 自动识别并处理登录过程中的滑块验证码，简化操作。*   **官方数据同步**: 对接学校官方查询接口，获取权威的电费使用数据。
*   **用电趋势预测**: 基于历史用电数据，利用机器学习算法预测未来电量消耗趋势及大致的欠费日期。*   **Server酱消息推送**: 当电量低于预设阈值或预测到可能欠费时，可通过 Server酱 发送微信通知，以便及时充值。

## 部署须知与教程

请按照以下步骤进行部署和配置：

**1. 环境准备**
*   一台可连接至**校园网内网**的设备 (例如：个人电脑、服务器、树莓派等)。
*   该设备需保持**24小时在线联网**，以确保脚本能够按计划持续运行和监测。
*   **Python 3.x** 环境。(Python 3.11测试通过)

**2. 下载代码**

您可以通过直接下载项目的 ZIP 压缩包并解压，或者使用 `git` (推荐此方式，便于后续获取更新) 来获取项目代码：
```bash
git clone https://github.com/xzzvsxd/SZU_Electricity_Bill_Inquiry_Assistant.git
cd SZU_Electricity_Bill_Inquiry_Assistant # 进入项目目录
```

**3. 安装依赖**

项目运行依赖若干第三方 Python 库。请在项目目录下打开终端或命令行，运行以下命令进行安装：
```bash
pip install httpx numpy opencv-python beautifulsoup4 pycryptodome
```
(提示: 若 `opencv-python` 库安装速度较慢，可以尝试更换为国内的 pip 镜像源。)

**4. 核心配置**

打开项目中的核心脚本文件 `main.py`，找到文件顶部的 `========== 配置区 ============` 部分。您需要根据自己的实际情况，修改以下三个关键参数：

*   `USERNAME`: 您的**学号** (请使用字符串格式，例如: `"2410xxxxxx"`)
*   `PASSWORD`: 您的学校统一认证**密码** (请使用字符串格式，例如: `"your_actual_password"`)
*   `SERVERCHAN_KEY`: 您的 **Server酱 KEY** (这是一个列表，即使您只有一个KEY，也需要用方括号包起来，例如: `["SCT123456abcdeFGHJKLMNopqrstUVWXYZ"]`)
*   **如何获取 Server酱 KEY？** Server酱是一项能将消息推送到您微信的服务。您可以访问其官方网站 [https://sct.ftqq.com/r/10928](https://sct.ftqq.com/r/10928) 注册并获取您的专属 KEY。

**配置代码示例:**

```python
# ========== 配置区 ============
USERNAME = os.environ.get("SZU_USER", "您的学号")  # 此处填入您的学号
PASSWORD = os.environ.get("SZU_PWD", "您的密码")  # 此处填入您的密码
SERVERCHAN_KEY = [os.environ.get("SERVERCHAN_KEY", "您的Server酱KEY")] # 此处填入您的Server酱密钥
```

**重要建议：** 为了配置的灵活性和安全性，脚本设计为优先读取环境变量。您可以不直接修改代码中的默认值，而是通过设置操作系统的环境变量来传入这些敏感信息。
例如，在 Linux 或 macOS 系统中，可以在运行脚本前执行：
```bash
export SZU_USER="您的学号"
export SZU_PWD="您的密码"
export SERVERCHAN_KEY="您的Server酱KEY"
```

Windows 用户则可以在“系统属性”的“环境变量”设置界面中添加这些变量。

**5. 运行脚本**

完成上述配置后，即可运行主脚本：

```bash
python main.py
```

*   **首次运行与调试**: 脚本在 `if __name__ == "__main__":` 部分的 `mode`变量默认为 `"debug"`。在此模式下，脚本会执行一次完整的登录、数据获取和预测流程，并在控制台输出详细的日志信息。请您务必检查这些日志，确保脚本能够无错误地运行，并且成功获取到电费信息及预测结果。

*   **切换到正式后台定时运行**:
    确认 `debug` 模式运行无误后，您需要编辑 `main.py` 文件末尾的 `if __name__ == "__main__":` 代码块，并将 `mode = "debug"` 修改为 `mode = "run"` (或者任何其他非 `"debug"` 的字符串)。    
```python
    # 示例修改，位于 main.py 文件末尾
    if __name__ == "__main__":
        print("【电费通知守护进程启动】")
        mode = "run" # 将 "debug" 修改为 "run" 以启用定时任务
        # ... 后续的循环和调度逻辑将生效
```
保存文件后，再次运行 `python main.py`。此时，脚本将按照预设的定时策略（例如每天特定时间）进入循环检查和通知模式。
为了确保脚本在您关闭终端或注销用户后仍能持续在后台稳定运行，推荐在 Linux/macOS 环境下使用 `nohup` 命令，或者使用 `screen` / `tmux` 等会话管理工具：
```bash
nohup python main.py > electricity.log 2>&1 &
```
上述 `nohup` 命令会将所有标准输出和错误输出重定向到 `electricity.log` 文件中，方便后续查看运行状态，并通过 `&` 使其在后台执行。
